Why smooth scroll?

Smooth scroll used to be a hard sell — hacky, heavy, inaccessible. Not anymore. Lenis settled the debate and quietly became the standard behind some of the web’s most ambitious work. Here’s what it unlocks for your sites.

Create more immersive interfaces

Unlock the creative potential and impact of your web experiences. Smoothing the scroll pulls users into the flow of the experience that feels so substantial that they forget they’re navigating a web page.

One feel, every input

Wheel, trackpad, or touch — Lenis gives everyone the same silky scroll. Dial in exactly how heavy, fast, or responsive it should feel, and it stays consistent across every device. Magic!

Make your animations flawless

Those jumps and delays in scroll-linked animations come from browsers running effects asynchronously with native scroll. Lenis was built to keep WebGL and the DOM perfectly in sync — so everything moves together, frame for frame.

Ship it in a single line

One call to new Lenis() and you’re done. Prefer no-code? Drop in the Framer plugin. Either way: no CSS transforms, no hijacked scrollbars, no accessibility trade-offs.

Lenis runs the web

What began as an internal tool for syncing WebGL and the DOM is now the default smooth scroll across the industry — even powering libraries like Locomotive Scroll. The smoothness was a happy accident. So we open-sourced the whole thing.
