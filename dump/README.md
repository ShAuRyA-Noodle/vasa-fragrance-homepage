# Archived site work

These files are retained for reference and restoration, but excluded from the production build.

- `previous-site-variations/`: eight earlier homepage concepts (`00`–`04`, `06`–`08`). The `05-campaign/` folder remains in production because the live homepage imports its CSS and JavaScript.
- `research-and-qa/`: design/reference snapshots, documentation, image-generation brief and QA captures.
- `unfinished-discover/`: unpublished `09-discover` draft and its media assets. To restore it, move `09-discover/` back to the site root, move `media-discover/` to `public/media/discover/`, then deliberately re-add it to the build and navigation.

The source media in `public/media/` was left intact unless it belonged exclusively to the Discover draft; live references must keep resolving. No archived work was deleted.
